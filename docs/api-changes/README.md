# API changes

One file for each pull request that changes the relay's API. Name it for the ticket, such as
`421-stop-version-clash.md`. Its first line is `MAJOR:`, `MINOR:` or `PATCH:`, then what changed.
Add no number: the version is worked out from these files (`relay/api-version.js`). Rules in
`docs/constitution.md`, article 15.
