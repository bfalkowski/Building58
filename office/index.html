    Use your own terminal instead
    
                Add the room hooks to ~/.claude/settings.json once, then every new claude session on this computer gets a worker here while the relay runs. You can watch those sessions but only type into the ones added above:
                
    
                RELAY_KEY=pick-a-key npm run office:hooks
                
    
                To take them out: node relay/office-hook.js --uninstall. Each hook event is trimmed before it leaves the hook: skill names, file names and the first two words of shell commands. Prompts are not sent unless you set OFFICE_SHOW_PROMPTS=1. See what the hook sends.
                
  
                

  
    
                
      
                Settings
                These switches control what the room does without you. The relay keeps them, so they stay set when you close this page or restart the relay.
                
      
    
                
    
                
      
                Trust level
                Each level lets the room do one more step without you. The levels follow the trust ladder in the constitution (article 5). Select a level and read what it will change. Then press Set level. You can still change each switch by hand below.

                The relay reads each value when it uses it, so a change applies immediately. No restart is necessary. A value that you set here replaces the environment variable for that setting.
